# Matriz do Destino: guia de estudo

Um roteiro em português para observar símbolos, comparar exemplos e formular perguntas concretas.

A [Calculadora Matriz do Destino](https://calculadoramatrizdodestino.com/) permite calcular a matriz gratuitamente pela data de nascimento e consultar explicações em português.

## Como usar

1. Escolha uma pergunta observável antes de ler o diagrama.
2. Registre exemplos e contraexemplos da sua experiência.
3. Transforme a reflexão em uma ação pequena que possa ser avaliada depois.
